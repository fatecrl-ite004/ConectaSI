# 🎓 ConectaSI - Plataforma Acadêmica e Profissional

O **ConectaSI** é um dashboard acadêmico modular desenvolvido para centralizar a rotina de estudos, organização de materiais, acompanhamento de atividades, avisos acadêmicos e divulgação de vagas de estágio para os alunos do curso de **Tecnologia em Sistemas para Internet da FATEC**.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de front-end, priorizando a semântica, a modularidade e a responsividade:
* **HTML5 Semantic:** Estruturação limpa e acessível de todas as telas.
* **CSS3:** Estilização centralizada e customizada, utilizando **Flexbox** e **CSS Grid** para o design responsivo.
* **Git e GitHub:** Controle de versionamento e hospedagem do código-fonte.

---

## 📂 Estrutura do Projeto

A interface conta com 7 páginas principais interconectadas por um menu lateral padrão:

| Página | Arquivo | Descrição |
| :--- | :--- | :--- |
| **Início** | `index.html` | Dashboard principal com métricas, resumo de progresso e avisos recentes. |
| **Disciplinas** | `disciplinas.html` | Listagem das matérias matriculadas e percentual de progresso. |
| **Materiais** | `materiais.html` | Repositório de arquivos, slides e apostilas por disciplina. |
| **Atividades** | `atividades.html` | Quadro de tarefas acadêmicas, prazos de entrega e status. |
| **Avisos** | `avisos.html` | Mural oficial de comunicados da coordenação e professores. |
| **Vagas de Estágio** | `estagios.html` | Vitrine de oportunidades de trabalho na área de TI. |
| **Perfil** | `perfil.html` | Dados cadastrais e acadêmicos do aluno. |

## ⚙️ Pré-requisitos

Para executar e visualizar o projeto localmente em sua máquina, você precisará apenas de:
1. Um navegador web moderno (Google Chrome, Microsoft Edge, Firefox ou Safari).
2. Opcional (recomendado para desenvolvimento): **VS Code** (Visual Studio Code) ou outro editor de código de sua preferência.
3. A extensão **Live Server** (no VS Code) para facilitar a visualização em tempo real.
